## User Stories

Use the format: *"As a [user type], I want to [action] so that [benefit]."*

Each story should have:
- **Story Points** (1, 2, 3, 5, or 8 — use Fibonacci scale)
- **Priority** (High / Medium / Low)
- **Status** (To Do / In Progress / Done)
- **Acceptance Criteria** (how will we know it's done?)

---

### Story 1

**Title:** Data Sharing

**User Story:**
> As a user, I want to access my saved task and project data so that I can review my progress and keep track of work history.

**Story Points:** 3
**Priority:** Low
**Status:** To Do

**Acceptance Criteria:**
- [ ] Data is stored in a reliable and accessible location for the user.
- [ ] The user can open and review their saved project/task information from the app.
- [ ] The data is restricted to the user and not exposed publicly.

---

### Story 2

**Title:** Task Management

**User Story:**
> As a project manager, I want to create, update, and organize tasks on a shared board so that the team can track progress and priorities.

**Story Points:** 5
**Priority:** High
**Status:** To Do

**Acceptance Criteria:**
- [ ] A user can create a task with a title, description, due date, and assignee.
- [ ] A user can change a task status from To Do to In Progress to Done.
- [ ] Tasks are visible on the board and organized in a way that supports prioritization.

---

### Story 3

**Title:** Team Collaboration

**User Story:**
> As a team member, I want to comment on tasks and view updates from teammates so that we can collaborate effectively and avoid missed work.

**Story Points:** 3
**Priority:** Medium
**Status:** To Do

**Acceptance Criteria:**
- [ ] Team members can add comments or notes to a task.
- [ ] Task updates appear in chronological order for easy review.
- [ ] Only authorized team members can view and edit assigned tasks.
